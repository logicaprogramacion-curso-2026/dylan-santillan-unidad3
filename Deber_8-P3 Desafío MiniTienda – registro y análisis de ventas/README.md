# 🏪 MiniTienda – Registro y Análisis de Ventas

## 📋 Descripción
Sistema de consola para gestionar una tienda pequeña con capacidades de registro de ventas, análisis estadístico y visualización de datos.

## 🚀 Características Principales

### Estructuras de Datos
- **Tuplas**: Catálogo de productos (inmutable)
- **Diccionarios**: Precios y stock de productos
- **Listas**: Buffer de ventas y registro de IDs

### Funcionalidades
1. **Registro de Ventas**: Con validación de stock y productos
2. **Exportación CSV**: Guarda ventas en formato CSV usando Pandas
3. **Análisis Estadístico**: Cálculo de métricas con NumPy
4. **Visualización**: Gráficos de barras con Matplotlib
5. **Gestión de Catálogo**: Agregar nuevos productos
6. **Sistema de Logs**: Registro de actividades y errores
